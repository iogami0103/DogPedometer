# ワンワン万歩計 サポートページ

歩いて犬を集める楽しい歩数計アプリ

## アプリについて

ワンワン万歩計は、歩くだけで可愛い犬のイラストがもらえる万歩計アプリです。400種類以上の犬をコレクションして、毎日の散歩をもっと楽しくしましょう。
